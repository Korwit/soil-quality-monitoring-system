# 🌱 Soil Quality Monitoring System with Geolocation ระบบตรวจวัดคุณภาพดินพร้อมระบุตำแหน่งทางภูมิศาสตร์

ระบบอัจฉริยะสำหรับการติดตาม วิเคราะห์ และจัดการคุณภาพของดินผ่านเซนเซอร์ NPK แบบเรียลไทม์

## 🌍 ภาพรวมโปรเจกต์

ระบบนี้เป็นโซลูชัน IoT แบบครบวงจรที่ช่วยให้เกษตรกรสามารถ:
- ✅ ติดตามระดับ NPK (ไนโตรเจน ฟอสฟอรัส โพแทสเซียม) ของดินแบบเรียลไทม์
- ✅ วิเคราะห์แนวโน้มคุณภาพดินผ่านเวลา
- ✅ รับคำแนะนำในการปรับปรุงคุณภาพดิน
- ✅ เข้าถึงข้อมูลจากอุปกรณ์มือถือ แท็บเล็ต หรือเว็บ

## 🚀 เว็บแอปพลิเคชัน

ลองใช้เว็บแอปพลิเคชันได้ที่: **[NPK Sensor Web App](https://npk-sensor-51b5c.web.app/)**

- **Dart**: เวอร์ชัน 2.17 หรือใหม่กว่า

### การติดตั้ง

#### 1. Clone Repository
```bash
git clone https://github.com/Korwit/soil-quality-monitoring-system.git
cd soil-quality-monitoring-system
```

#### 2. ตั้งค่าแอปพลิเคชัน Flutter
```bash
cd flutter
flutter pub get
flutter run
```

#### 3. ตั้งค่าเว็บแอปพลิเคชัน
```bash
cd web
npm install
npm start
```

#### 4. ตั้งค่าฟาร์มแวร์
```bash
cd embedded
mkdir build
cd build
cmake ..
make
```
